svgplot

markdown 문서에 박아넣을, 심미성 있고 수정이 쉬운 정적 SVG 차트를 만드는 Python 패키지.

import svgplot as sp

data = {"day": [1, 2, 3, 4, 5], "sales": [10.0, 15.0, 7.0, 20.0, 12.0]}
sp.lineplot(data, x="day", y="sales").save("chart.svg")

무엇이 다른가

렌더 후에도 다시 칠할 수 있다
좌표 덤프가 아니라 의미 있는 CSS 클래스를 붙인다. 색을 바꾸려고 차트를 다시 그릴 필요가 없다 — 스타일시트를 고치면 된다.
손으로 고칠 수 있다
출력이 사람이 읽을 수 있는 SVG다. 한 줄을 지우거나 값을 고치는 일이 에디터에서 끝난다.
접근성이 기본값이다
모든 차트가 role="img"와 <title>·<desc>를 내보낸다. <desc>는 제목을 되풀이하지 않고 차트 종류·데이터 규모·값 범위를 실제로 말한다.
같은 입력이면 같은 SVG
난수를 쓰는 곳은 시드를 받는다. 문서 빌드에서 diff 가 흔들리지 않는다.
