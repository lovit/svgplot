svgplot · 갤러리

pieplot

값 하나짜리 컬럼을 원의 조각으로 나눈다. 조각의 각도가 전체 합에 대한 비율이다.

데이터
values: 수치(음수 불가, 전부 0 이면 거부) · labels(선택): 조각 이름

데이터

import svgplot as sp

BUDGET = {
    "항목": ["인건비", "임대료", "마케팅", "장비", "기타"],
    "금액": [4200.0, 1800.0, 1500.0, 900.0, 600.0],
}

예시

기본 — labels= 를 주지 않으면 조각 번호가 이름이 된다

sp.pieplot(BUDGET, values="금액")

labels= 로 조각에 이름을 붙인다

sp.pieplot(BUDGET, values="금액", labels="항목")

inner_radius= 는 가운데를 비운다(도넛)

sp.pieplot(BUDGET, values="금액", labels="항목", inner_radius=0.45)

info= 로 각주 표를 함께 낸 예산 도넛

sp.pieplot(BUDGET, values="금액", labels="항목", info=[("항목", "@항목"), ("금액", "@금액{0,0}")])

tooltip=True — 조각마다 자기 비율과 *거기까지의 누적 비율*을 말한다

sp.pieplot(BUDGET, values="금액", labels="항목", tooltip=True)

메모

  • 다섯 번째 그림에는 체크박스가 없다. 조각 하나가 행 하나라서 토글은 범례가 아니라 데이터 편집이 된다.
  • 누적 비율이 그림 안에 있으면서 어디에도 안 적혀 있는 것이다. 파이는 12시에서 시계방향으로 읽으므로 조각이 *끝나는 자리*가 이미 전체에 대한 진술이다 — "이 넷을 합치면 대부분" 은 파이에 가장 자주 묻는 질문인데, 눈으로 답하려면 조각을 다시 더해야 한다. 차트는 조각마다 값을 가운데 적고 범례는 이름을 붙이지만, 둘 다 독자가 어디까지 돌았는지는 말하지 않는다.
  • 누적은 반올림한 비율이 아니라 값에서 누적한다. 1/1/1 은 비율이 33.3% 셋이라 더하면 99.9% 지만 마지막 조각의 누적은 100.0% 다 — 그 수가 뜻하는 것은 "쐐기가 첫 조각이 시작한 자리에서 끝난다" 이기 때문이다.
  • tooltip=True 일 때만 값 라벨이 pointer-events: none 을 받는다. 라벨의 기준점은 언제나 자기 조각 안이고 라벨이 조각 뒤에 그려지므로, 독자가 겨냥하는 바로 그 자리에서 포인터를 가져간다. tooltip=False 에서는 조각에 놓을 것이 없어서 조건부다.
  • 얇은 조각에서는 *글자*가 자기 조각 밖으로 삐져나온다. 1000 대 1 이면 "1" 이 폭 1.1px 짜리 쐐기 위에 6px 짜리 글자로 앉는다 — 그 글자를 가리키면 옆 조각의 툴팁이 뜬다. 규칙이 없을 때는 거기서 아무것도 안 뜨므로 여전히 나아진 것이지만, 라벨이 자기 조각을 덮는다는 말은 기준점에 대해서만 참이다.
  • 누적이 100.0% 로 읽히는 조각이 마지막 조각뿐인 것도 아니다. 1e9 대 1 이면 첫 조각이 이미 100.0% 로 반올림된다. 소수점 한 자리의 대가이고, 마지막 조각이 100.0% 라는 것 자체는 언제나 참이다.
  • 음수와 비유한 값을 라벨명을 대고 거부하고, 합이 0 이면 거부한다. 각도로 나눌 전체가 없기 때문이다.
  • inner_radius= 는 [0, 1) 안의 값이다 — 바깥 반지름에 대한 비율이고, 1 이면 조각이 사라진다.
  • 항상 범례를 그린다. 조각 안에 이름을 넣지 않는 이유는 좁은 조각에 글자가 들어가지 않기 때문이다.
  • info= 를 받는 세 차트 중 하나다(나머지는 lineplot·scatterplot). 한 행이 한 조각이라 표의 행과 그림의 마크가 일대일로 맞기 때문이다.
