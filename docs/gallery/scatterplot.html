svgplot · 갤러리

scatterplot

x·y 두 수치 컬럼을 점으로 놓는다. hue= 는 색, size= 는 마커 크기에 매핑한다.

데이터
x: 수치 · y: 수치 · hue(선택): 아무 타입 · size(선택): 수치

데이터

import svgplot as sp

STORES = {
    "면적": [30.0, 45.0, 60.0, 85.0, 120.0, 25.0, 50.0, 70.0, 95.0, 140.0],
    "매출": [8.0, 14.0, 17.0, 26.0, 31.0, 6.0, 15.0, 21.0, 27.0, 38.0],
    "직원수": [2.0, 3.0, 4.0, 6.0, 9.0, 2.0, 4.0, 5.0, 7.0, 11.0],
    "지역": ["수도권"] * 5 + ["지방"] * 5,
}

예시

체크를 끄면 시리즈가 사라지지 않고 흐려진다. 축·눈금·카테고리 밴드는 그릴 때 한 번 정해지고 다시 계산되지 않으므로, 감추면 남은 그림이 자기보다 넓은 축 위에 서게 된다. 흐리게 하는 것은 "이건 지금 보지 말라"는 말이고, 감추는 것은 "이 값은 없다"는 말이다 — 뒤쪽은 사실이 아니다.

기본

sp.scatterplot(STORES, x="면적", y="매출")

hue= 는 점 색을 나눈다

sp.scatterplot(STORES, x="면적", y="매출", hue="지역")

size= 는 세 번째 수치를 마커 반지름에 매핑한다

sp.scatterplot(STORES, x="면적", y="매출", size="직원수")

tooltip=True — 점마다 자기 값을 말한다

sp.scatterplot(STORES, x="면적", y="매출", hue="지역", size="직원수", tooltip=True)

yscale="log" — 값이 자릿수로 벌어질 때

LATENCY = {
    "요청수": [10.0, 100.0, 1000.0, 10000.0, 100000.0],
    "지연ms": [1.2, 3.0, 14.0, 130.0, 1400.0],
}
sp.scatterplot(LATENCY, x="요청수", y="지연ms", xscale="log", yscale="log")

메모

  • 이 페이지의 두 번째 그림에는 체크박스가, 네 번째에는 마우스오버 강조가 붙어 있다. 둘 다 이 페이지의 CSS 와 마크업이고 JavaScript 는 0줄이다.
  • tooltip=True 는 점마다 <title> 을 붙인다. 브라우저가 그걸 마우스오버 툴팁으로 띄우고, 같은 것이 그 점의 접근 가능한 이름이 된다 — 점 무더기 하나가 아니라 이름이 있는 마크 여러 개가 된다. <img> 로 넣은 SVG 에서는 동작하지 않는다: 그건 별개 문서라 브라우저가 상호작용 없이 그린다.
  • tooltip=False 가 기본이다. 마크마다 <title> 은 마크마다 요소이므로 점 1000개짜리 차트는 요소 1000개가 늘고, 기존 사용자의 출력 바이트가 요청하지 않은 기능 때문에 전부 바뀐다. 꺼두면 파일은 예전 그대로다.
  • hue= 와 size= 를 함께 주면 범례가 둘 쌓인다. 캔버스가 그 높이를 감당하지 못하면 잘라 그리는 대신 거부한다.
  • size= 의 반지름은 theme.marker_size 의 0.5배에서 2.5배 사이로 매핑된다. 값이 하나뿐이면 전부 기본 크기가 된다.
  • 로그 축은 0 이하 값을 컬럼명을 대고 거부한다. ylim= 이 그 값을 도메인 밖으로 밀어내도 그린다면 마찬가지로 거부한다.
