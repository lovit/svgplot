svgplot · 갤러리

regplot

산점도 위에 최소제곱 적합선을 얹고, 부트스트랩으로 잡은 신뢰대역을 함께 그린다.

데이터
x: 수치 · y: 수치 · x·y 가 모두 있는 행이 3개 이상 · hue 는 받지 않는다

데이터

import random

import svgplot as sp

_rng = random.Random(17)
_ad = [round(_rng.uniform(5, 95), 1) for _ in range(60)]
SPEND = {
    "광고비": _ad,
    "문의수": [round(18 + 1.9 * value + _rng.gauss(0, 22), 1) for value in _ad],
}

예시

기본 — 95% 신뢰대역과 산점도

sp.regplot(SPEND, x="광고비", y="문의수")

ci=None 은 대역 없이 선만 그린다

sp.regplot(SPEND, x="광고비", y="문의수", ci=None)

ci=0.99 는 대역을 넓힌다

sp.regplot(SPEND, x="광고비", y="문의수", ci=0.99)

scatter=False 는 점을 빼고 적합만 남긴다

sp.regplot(SPEND, x="광고비", y="문의수", scatter=False)

tooltip=True — 신뢰대역이 이름 있는 대상이 된다

sp.regplot(SPEND, x="광고비", y="문의수", tooltip=True)

메모

  • 다섯 번째 그림에는 체크박스가 없다. hue= 가 없으니 끄고 켤 시리즈가 없다.
  • tooltip=True 가 점마다 x·y 를 말하고, **신뢰대역에도 <title> 을 준다.** 이 차트가 다른 차트에 더하는 것이 그 두 번째다 — 선은 누가 봐도 적합이고 점은 누가 봐도 관측인데, 선을 감싼 반투명 영역은 뭔가 이름이 붙기 전까지 장식으로 읽힌다. 차트의 <desc> 가 그림 전체에 대해 한 번 말하지만, 대역을 가리키고 있는 독자에게 읽히는 것은 그게 아니다.
  • 대역은 자기가 몇 % 구간인지와 몇 번의 부트스트랩 재표본에서 나왔는지를 말한다. n_boot 은 구현 세부가 아니라 답의 일부다 — 부트스트랩 구간은 그 수에 따라 자기 정밀도가 달라지는 추정이고, 같은 데이터라도 n_boot 이 다르면 다른 대역이 그려진다.
  • 가리키기 가장 쉬운 마크이기도 하다. 선은 2px(print 프리셋은 2.5px)인데 대역은 면적이다.
  • 적합선 자체에는 <title> 을 안 주고, 대신 포인터의 길에서 뺀다. 선은 맨 나중에 그려지므로 2px 스트로크가 대역 한가운데를 덮고, 제목 없이 히트 테스트에 걸리면 <title> 을 가진 가장 가까운 조상 — 루트 <svg>, 즉 차트 이름 — 이 답한다. 독자가 가장 자주 겨냥할 선이 가장 적게 말하는 셈이다. 선에 제목을 붙이는 것으로는 안 고쳐진다: <title> 은 히트 테스트 대상이 아니라 *무슨 글자가 뜨는지*만 바꾸지 어느 요소가 포인터를 받는지는 안 바꾼다. pointer-events: none 이라야 밑의 대역이 답한다.
  • ci=None 이면 대역이 안 그려지므로 대역 툴팁도 없고, scatter=False 면 점 툴팁이 없다. 걸 요소가 없으면 이름을 걸 수 없다.
  • 같은 데이터와 같은 seed= 면 SVG 가 바이트 단위로 같다. 부트스트랩은 지역 난수 생성기를 쓰고 seed 의 기본값이 0 이다.
  • ci=None 이면 부트스트랩 자체를 건너뛴다. 대역이 필요 없을 때 n_boot 만큼의 계산이 사라진다.
  • x·y 가 모두 있는 행이 3개 미만이면 거부한다. 점 둘로 그은 선에는 신뢰대역이 의미를 갖지 않는다.
  • hue= 가 없다. 그룹마다 적합을 따로 하려면 facet 으로 패널을 나눈다.
  • logistic·robust·lowess 적합은 범위 밖이다 — statsmodels 의존이 생기고, 이 패키지는 런타임 의존성을 두지 않는다.
