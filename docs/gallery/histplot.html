svgplot · 갤러리

histplot

수치 한 컬럼을 구간으로 나눠 각 구간에 든 행 수를 막대로 그린다.

데이터
x: 수치 · hue(선택): 아무 타입 · y 는 받지 않는다(높이는 개수다)

데이터

import random

import svgplot as sp

_rng = random.Random(7)
WAIT = {
    "대기분": [round(_rng.gauss(12, 4), 1) for _ in range(120)]
    + [round(_rng.gauss(20, 5), 1) for _ in range(120)],
    "창구": ["일반"] * 120 + ["우선"] * 120,
}

예시

체크를 끄면 시리즈가 사라지지 않고 흐려진다. 축·눈금·카테고리 밴드는 그릴 때 한 번 정해지고 다시 계산되지 않으므로, 감추면 남은 그림이 자기보다 넓은 축 위에 서게 된다. 흐리게 하는 것은 "이건 지금 보지 말라"는 말이고, 감추는 것은 "이 값은 없다"는 말이다 — 뒤쪽은 사실이 아니다.

기본 — bins="auto" 가 구간 폭을 고른다

sp.histplot(WAIT, x="대기분")

bins= 에 정수를 주면 그 수만큼 나눈다

sp.histplot(WAIT, x="대기분", bins=12)

bins= 에 전략 이름을 줄 수도 있다

sp.histplot(WAIT, x="대기분", bins="sturges")

hue= 그룹은 하나의 구간 경계를 공유한다

sp.histplot(WAIT, x="대기분", hue="창구")

tooltip=True — 막대마다 자기 구간과 도수를 말한다

sp.histplot(WAIT, x="대기분", hue="창구", tooltip=True)

메모

  • 네 번째와 다섯 번째 그림에 체크박스가 붙어 있다. 이 페이지의 CSS 와 마크업이고 JavaScript 는 0줄이다.
  • tooltip=True 는 막대마다 <title> 을 붙인다. 말하는 것은 그 구간의 양끝과 도수뿐이고 어느 행이었는지는 말하지 않는다 — 말할 수 없다. 막대는 행이 아니라 개수이고, 그 개수를 만든 값들은 세고 난 뒤에는 어디에도 남지 않는다. scatterplot 의 점은 행이라 자기 행을 되읽지만 여기에는 되읽을 행이 없다.
  • 대괄호가 어느 쪽 끝이 열려 있는지 말한다. [12, 18) 은 12 를 포함하고 18 을 포함하지 않는다. 마지막 구간만 [a, b] 로 닫히는데, 그래야 데이터의 최댓값이 조용히 빠지지 않는다. "12 - 18" 과 "18 - 24" 로 적으면 18 이 어느 막대로 갔는지 읽는 쪽이 알 수 없고, 두 막대가 서로 다르게 답한다.
  • 구간 경계는 계산된 수라 자릿수가 길다. 위 그림의 경계 하나는 4.790909090909091 이고, 가장 긴 <title> 이 72자, 파일은 5,672 에서 7,484 바이트가 된다. 반올림하면 짧아지지만 경계가 움직인다 — [4.79, 7.68) 은 [4.790909…, 7.681818…) 과 다른 구간을 뜻한다. 7.681 은 실제 경계 안이고 반올림한 경계 밖이다. 위 데이터는 소수점 한 자리로 반올림돼 있어서 그 사이에 든 값이 마침 없지만, 구간이 뜻하는 바는 그것과 무관하게 달라진다. 툴팁은 정확한 철자를 쓴다.
  • hue= 로 두 그룹을 겹쳐 그리면 겹친 자리에서는 문서 순서상 나중에 그려진 쪽이 포인터를 가져간다. 위 그림은 x 슬롯 다섯 개를 두 그룹이 함께 쓰고, 그중 네 곳에서는 뒤에 그려지는 "일반" 의 툴팁만 뜬다. opacity 0.75 라 아래쪽이 비쳐 보이지만 포인터는 거기에 닿지 않는다.
  • 다섯 번째 슬롯은 반대다. 거기서는 먼저 그려진 "우선" 막대가 "일반" 막대보다 48.75px 더 높아서, 그 위쪽 띠에서는 "우선" 이 맨 위 요소이고 자기 툴팁을 낸다. 문서 순서가 정하는 것은 *겹친 자리*뿐이고, 뒤쪽 막대가 더 크면 자기 머리는 언제나 드러난다.
  • bins= 는 정수 또는 전략 이름을 받는다 — auto·fd·doane·scott·rice·sturges·sqrt. 전략은 numpy 의 것을 그대로 다시 구현한 것이라 경계가 numpy 와 비트 단위로 같다.
  • hue= 를 주면 그룹들이 하나의 구간 경계를 공유한다. 그래야 막대 하나가 뜻하는 양이 그룹마다 같아 높이끼리 견줘진다.
  • 정수 bins= 는 10,000 에서 막는다. 그보다 많은 막대는 캔버스 폭에서 한 픽셀 아래로 내려간다.
  • 높이가 개수이므로 y 컬럼이 없다. 값의 분포를 곡선으로 보려면 kdeplot, 누적으로 보려면 ecdfplot 을 쓴다.
