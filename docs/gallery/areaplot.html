svgplot · 갤러리

areaplot

선 아래를 0까지 채운다. 채워진 면적이 값이므로 y 축은 항상 0을 포함한다.

데이터
x: 수치(날짜는 받지 않는다) · y: 수치 · hue(선택): 아무 타입

데이터

import svgplot as sp

TRAFFIC = {
    "주차": [1, 2, 3, 4, 5, 6, 1, 2, 3, 4, 5, 6],
    "방문": [120.0, 180.0, 150.0, 240.0, 210.0, 300.0, 60.0, 75.0, 110.0, 95.0, 140.0, 160.0],
    "유입": ["검색"] * 6 + ["추천"] * 6,
}

예시

체크를 끄면 시리즈가 사라지지 않고 흐려진다. 축·눈금·카테고리 밴드는 그릴 때 한 번 정해지고 다시 계산되지 않으므로, 감추면 남은 그림이 자기보다 넓은 축 위에 서게 된다. 흐리게 하는 것은 "이건 지금 보지 말라"는 말이고, 감추는 것은 "이 값은 없다"는 말이다 — 뒤쪽은 사실이 아니다.

기본

ONE_SERIES = {"주차": [1, 2, 3, 4, 5, 6], "방문": [120.0, 180.0, 150.0, 240.0, 210.0, 300.0]}
sp.areaplot(ONE_SERIES, x="주차", y="방문")

hue= 는 시리즈를 겹쳐 그린다

sp.areaplot(TRAFFIC, x="주차", y="방문", hue="유입")

stacked=True 는 쌓아서 합계를 보이게 한다

sp.areaplot(TRAFFIC, x="주차", y="방문", hue="유입", stacked=True)

xscale="log" — x 가 자릿수로 벌어질 때

SIZES = {"바이트": [1.0, 10.0, 100.0, 1000.0, 10000.0], "누적": [2.0, 9.0, 31.0, 68.0, 100.0]}
sp.areaplot(SIZES, x="바이트", y="누적", xscale="log")

메모

  • 두 번째와 세 번째 그림에 체크박스와 마우스오버 강조가 붙어 있다. 이 페이지의 CSS 와 마크업이고 JavaScript 는 0줄이다.
  • 세 번째(누적)에서 한 층을 꺼도 나머지가 자리를 안 옮긴다. 옮길 수가 없다 — path 의 좌표는 그릴 때 한 번 박히고, 위층의 아래쪽 경계선이 곧 아래층의 위쪽 경계선이다. 그래서 감추면 위층이 내려앉는 게 아니라 그 자리에 그대로 뜬 채로 밑에 빈 띠가 생기고, 남은 그림은 자기보다 넓은 축 위에 서게 된다. 면적 차트에서 그게 특히 잘 보이는 이유는 값이 높이가 아니라 넓이여서, 축이 남긴 빈 자리가 곧 값처럼 읽히기 때문이다.
  • 체크를 끈 시리즈는 포인터의 길에서 아예 빠진다. 두 가지가 함께 필요했다 — 강조 규칙을 :checked 에 걸어 두 규칙이 서로 배타적이게 하고(안 그러면 꺼둔 시리즈에 커서를 올렸을 때 흐린 채로 테두리만 진해진다), 흐리게 하는 규칙에 pointer-events: none 을 넣는 것이다. opacity 는 요소를 히트 테스트에서 빼주지 않는다. 두 번째(겹쳐 그리기) 그림이 그 차이를 만든다 — series-2 의 면적이 series-1 안에 통째로 들어 있어서, series-2 를 꺼도 그게 포인터를 계속 삼키면 켜져 있는 series-1 이 그 아래 어디서도 반응하지 못한다.
  • 두 번째(겹쳐 그리기)에서 겹친 자리에 커서를 올리면 항상 위에 있는 것 하나만 강조된다. 문서 순서상 나중에 그려진 쪽이고, opacity 로 비쳐 보이는 아래쪽에는 포인터가 닿지 않는다 — 겹쳐 그린 그림이 원래 그렇다.
  • yscale= 이 없다. 채워진 면적이 곧 값이고 그것은 0에서 재는데, 로그 축에는 잴 0이 없어 채움이 임의의 자리에서 시작하고 면적이 무엇에도 비례하지 않게 된다.
  • x 에 date/datetime 을 받지 않는다. 시간축이 필요하면 lineplot 을 쓴다.
  • 같은 x 를 가진 행이 여럿이면 기본적으로 합산된다. estimator= 로 mean·median 등 다른 접기를 고를 수 있다.
  • stacked=True 일 때 x 축은 모든 그룹의 x 합집합이고, 어떤 (그룹, x) 조합에 행이 없으면 그 자리는 0으로 센다.
