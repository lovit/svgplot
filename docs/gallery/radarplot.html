svgplot · 갤러리

radarplot

카테고리를 원 둘레의 스포크에 놓고 값을 반지름으로 삼아 닫힌 다각형을 그린다.

데이터
x: 카테고리(3개 이상) · y: 수치(음수 불가, 전부 0 불가) · hue(선택): 시리즈

데이터

import svgplot as sp

_axes = ["속도", "내구성", "연비", "정숙성", "적재량", "가격"]
SPEC = {
    "항목": _axes * 2,
    "점수": [82.0, 64.0, 71.0, 55.0, 48.0, 60.0, 58.0, 88.0, 62.0, 79.0, 84.0, 45.0],
    "모델": ["A형"] * 6 + ["B형"] * 6,
}

예시

기본 — 시리즈 하나

ONE = {"항목": ["속도", "내구성", "연비", "정숙성", "적재량", "가격"], "점수": [82.0, 64.0, 71.0, 55.0, 48.0, 60.0]}
sp.radarplot(ONE, x="항목", y="점수")

hue= 는 시리즈마다 다각형을 하나씩 그린다

sp.radarplot(SPEC, x="항목", y="점수", hue="모델")

fill=False 는 윤곽만 남긴다 — 겹치는 시리즈가 서로를 가리지 않는다

sp.radarplot(SPEC, x="항목", y="점수", hue="모델", fill=False)

메모

  • 카테고리가 3개 미만이면 거부한다. 스포크 둘로는 면적이 생기지 않는다.
  • 모든 시리즈가 모든 스포크에 값을 가져야 한다. 하나라도 빠지면 다각형에 구멍이 생기므로 거부한다.
  • 음수를 거부한다. 반지름이 음수면 점이 반대쪽 스포크로 반사돼 데이터가 뜻하지 않은 자리에 놓인다.
  • 값이 전부 0 이면 거부한다. 나눌 반지름이 없다.
  • 눈금 링은 원이 아니라 다각형이다. 그래야 링이 모든 스포크를 그 눈금이 말하는 값에서 지난다.
  • 같은 카테고리가 한 시리즈 안에 두 번 나오면 마지막 행이 이긴다.
