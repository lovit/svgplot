svgplot · 갤러리

radarplot

카테고리를 원 둘레의 스포크에 놓고 값을 반지름으로 삼아 닫힌 다각형을 그린다.

데이터
x: 카테고리(3개 이상) · y: 수치(음수 불가, 전부 0 불가) · hue(선택): 아무 타입

데이터

import svgplot as sp

_axes = ["속도", "내구성", "연비", "정숙성", "적재량", "가격"]
SPEC = {
    "항목": _axes * 2,
    "점수": [82.0, 64.0, 71.0, 55.0, 48.0, 60.0, 58.0, 88.0, 62.0, 79.0, 84.0, 45.0],
    "모델": ["A형"] * 6 + ["B형"] * 6,
}

예시

체크를 끄면 시리즈가 사라지지 않고 흐려진다. 축·눈금·카테고리 밴드는 그릴 때 한 번 정해지고 다시 계산되지 않으므로, 감추면 남은 그림이 자기보다 넓은 축 위에 서게 된다. 흐리게 하는 것은 "이건 지금 보지 말라"는 말이고, 감추는 것은 "이 값은 없다"는 말이다 — 뒤쪽은 사실이 아니다.

기본 — hue= 가 없으면 다각형 하나를 채워 그린다

ONE = {"항목": ["속도", "내구성", "연비", "정숙성", "적재량", "가격"], "점수": [82.0, 64.0, 71.0, 55.0, 48.0, 60.0]}
sp.radarplot(ONE, x="항목", y="점수")

hue= 는 시리즈마다 다각형을 하나씩 그린다

sp.radarplot(SPEC, x="항목", y="점수", hue="모델")

fill=False 는 윤곽만 남긴다 — 겹치는 시리즈가 서로를 가리지 않는다

sp.radarplot(SPEC, x="항목", y="점수", hue="모델", fill=False)

메모

  • 두 번째와 세 번째 그림에 체크박스가 붙어 있다. 이 페이지의 CSS 와 마크업이고 JavaScript 는 0줄이다.
  • 두 번째와 세 번째는 같은 데이터를 fill= 만 바꿔 그린 것이다. 체크박스는 둘 다 있지만 마우스오버 강조는 두 번째에만 있다 — kdeplot 이 직교좌표에서 보여주는 대비를 극좌표에서 다시 본다.
  • fill=True 면 다각형 안쪽이 채워진 도형이라 커서가 그 안 아무 데나 있어도 잡힌다. fill=False 면 차트가 fill: none 을 내므로 커서가 닿는 면적이 선 굵기 2px 뿐이다 — 게다가 여기서는 그 선이 닫힌 다각형이라 가운데가 가장 넓은데도 거기에 아무것도 없다. :hover 를 달 수는 있지만 안 잡히므로 안 단다.
  • 세 번째가 fill=False 를 쓰는 이유 자체가 겹치는 시리즈가 서로를 가리지 않게 하려는 것이다. 그 선택이 가리킬 수 있는 것까지 바꾼다는 것이 이 페이지가 말하는 대가다.
  • 툴팁은 없다. 시리즈당 닫힌 <path> 가 하나라 걸 수 있는 것은 시리즈 이름뿐인데, 그건 범례가 이미 말한다. 꼭짓점마다 값을 말하려면 마커를 그려야 하는데 그건 상호작용이 아니라 차트 기능이다.
  • 카테고리가 3개 미만이면 거부한다. 스포크 둘로는 면적이 생기지 않는다.
  • 모든 시리즈가 모든 스포크에 값을 가져야 한다. 하나라도 빠지면 다각형에 구멍이 생기므로 거부한다.
  • 음수를 거부한다. 반지름이 음수면 점이 반대쪽 스포크로 반사돼 데이터가 뜻하지 않은 자리에 놓인다.
  • 값이 전부 0 이면 거부한다. 나눌 반지름이 없다.
  • 눈금 링은 원이 아니라 다각형이다. 그래야 링이 모든 스포크를 그 눈금이 말하는 값에서 지난다.
  • 같은 카테고리가 한 시리즈 안에 두 번 나오면 마지막 행이 이긴다.
