svgplot · 갤러리

gaugeplot

값 하나가 범위 안에서 어디쯤인지를 240도 아크의 채운 길이로 나타낸다.

데이터
values: 수치(무한대 거부, 결측은 버린다) · labels(선택): 아크 이름 · vmin(선택): 범위의 아래끝 · vmax(선택): 범위의 위끝

데이터

import svgplot as sp

KPI = {
    "지표": ["가동률", "적중률", "재구매율"],
    "값": [72.0, 91.0, 38.0],
}

예시

기본 — labels= 없는 한 행은 번호가 이름이 되고 범례가 없다, 범위는 vmin=/vmax= 가 정한다

ONE = {"값": [72.0]}
sp.gaugeplot(ONE, values="값", vmin=0.0, vmax=100.0)

여러 행은 하나의 vmin=/vmax= 범위를 공유하는 동심 아크가 된다

sp.gaugeplot(KPI, values="값", labels="지표", vmin=0.0, vmax=100.0)

vmin=/vmax= 를 주지 않으면 데이터에서 범위를 잡는다

sp.gaugeplot(KPI, values="값", labels="지표")

tooltip=True — 아크마다 자기 값과 *어떤 vmin=/vmax= 범위에 대고* 그려졌는지를 말한다

sp.gaugeplot(KPI, values="값", labels="지표", vmin=0.0, vmax=100.0, tooltip=True)

메모

  • 네 번째 그림에는 체크박스가 없다. 한 행이 아크 하나라서 토글은 범례가 아니라 데이터 편집이 된다. 대신 커서가 얹힌 아크의 테두리가 진해진다 — 아크는 원래 자기 색 테두리를 갖고 있고, hover 규칙이 그걸 거의 검정으로 바꾼다. 이 페이지의 CSS 이고 JavaScript 는 0줄이다.
  • tooltip=True 가 아크마다 <title> 에 이름·값·범위를 담는다. 반쯤 찬 아크는 양 끝을 모르면 아무 뜻이 없고, vmin= 의 기본값(0, 또는 최솟값이 음수면 그 값)은 보고 알아낼 수 있는 규칙이 아니다.
  • 눈금은 대개 *낮은* 쪽 끝에 라벨을 붙인다 — vmin= 이 0 이 기본이고 0 은 늘 좋은 눈금이라서다. 빠지는 것은 높은 쪽이다. vmax= 를 데이터에서 잡으면 좋은 수가 되는 일이 드물어서, 세 번째 그림은 [0, 91] 인데 눈금이 80 까지만 찍히고 91 은 어디에도 안 적힌다. 네 번째는 vmax=100.0 이라 눈금이 100 을 찍는다.
  • 그래서 세 번째와 네 번째는 같은 데이터인데 아크 길이가 다르고, 눈금 링을 읽으면 네 번째의 상한은 알 수 있지만 세 번째의 91 은 알 수 없다. 차트의 <desc> 는 예전부터 범위를 말해 왔다 — 새로 생긴 것은 *아크 하나*에게 무엇의 몫이냐고 물을 수 있다는 것이다.
  • vmin 이하 값은 아크가 아예 안 그려지므로 툴팁도 없다. 길이 0인 스윕은 양끝이 겹친 아크라 렌더러가 통째로 버리므로(SVG F.6.2), 이 차트는 그걸 아예 안 낸다. 걸 요소가 없으면 이름을 걸 수 없고, 없는 마크에 이름을 붙이면 값이 0이라는 것과 값이 없다는 것을 같은 말로 만든다.
  • 가운데 숫자는 포인터를 그대로 갖는다. 숫자가 아크 위에 있으니 치워야 한다고 처음에 썼는데 사실이 아니었다 — 아크는 고리 조각이고 그 채움은 가운데 구멍에서 끝나므로, 행이 열 개 이하면 어떤 숫자 밑에도 아크가 없다. 치우면 밑에서 나오는 것은 <title> 없는 배경 사각형이고, 대신 숫자를 마우스로 선택할 수 없게 된다.
  • 범위 밖 값은 스윕이 클램핑되지만 툴팁은 그 행이 든 수를 말한다. 클램핑된 수를 말하면 툴팁이 데이터를 읽어주는 게 아니라 두 번째 그림이 되고, 옆에 적힌 범위가 꽉 찬 아크를 설명해 준다.
  • 한 행이 아크 하나이고 바깥쪽부터 그린다. 모든 아크가 같은 범위를 쓰므로 길이끼리 견줘진다.
  • 범위 밖 값은 양 끝으로 클램핑된다. 감아 돌게 두면 vmax 를 넘은 큰 값이 더 작은 아크로 그려져 데이터를 뒤집어 보이게 된다.
  • 링이 3px 보다 얇아질 만큼 행이 많으면 거부한다. 그보다 얇은 링은 서로 구별되지 않는다.
  • vmin >= vmax 를 거부하고, 비유한 경계나 넘치는 범위도 거부한다.
  • 16종 중 데이터 모델이 비교가 아니라 스칼라인 유일한 차트다. 그래서 x/y 채널 대신 values= 컬럼 하나를 받는다 — pieplot·treemap 과 같은 자리, 같은 이름이다.
